Features

Everything between the editor and the motor.

Tulpa editor

Highlighting and an LSP client with live diagnostics, hover, completion, go-to-definition, an outline and find/replace.

MuJoCo co-simulation

One ▶ Run button. Programs that call cosim::connect() drive physics in lock-step, at full speed or real time ×N.

Live telemetry

tlm::plot streams to live plots. tlm::status drives the status bar, and tlm::artifact links output files.

Waveform viewer

VCD files from std/rtl or Verilog simulators, with zoom, pan, a cursor and signal filtering.

Machines & BOMs

Diagrams of every machine, plus BOM and netlist tables from std/eda.

Tulpa terminal

A live REPL. $ check main.rav runs tulpa, ! cmd runs the shell, and Ctrl+Enter sends the selection.

Bundled project

Morty, a humanoid written entirely in Tulpa.

The original Morty mixed ROS, PyTorch, Verilog and gEDA. The Tulpa rewrite keeps that architecture, and now every piece runs and can be checked.

  • RTL torque governorUART, CRC, clamp, slew and watchdog: 8/8 responses bit-exact.
  • Mainboard as codeERC, a power budget in watts, netlist and BOM.

Install

Get HermiSim.

Windows installer

Download HermiSim-Setup-<version>-x64.exe. It bundles the IDE, MuJoCo and the Tulpa toolchain, installs per user without admin rights, can add tulpa to PATH, and associates .rav/.tlp files.

Linux, macOS or Windows. Clone both repositories side by side.
