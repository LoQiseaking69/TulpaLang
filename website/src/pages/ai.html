An AI that knows Tulpa, and checks its work.

Tulpa AI is the agentic platform for Tulpa developers. Ask it to write a driver, fix a compiler error or explain a state machine. Before it answers, it runs the code through the real tulpa toolchain and repairs what fails.

What it does

A pair programmer for the physical world.

Write

Programs, drivers, state machines and missions in idiomatic Tulpa, with units and contracts where they belong.

Fix

Paste a compiler diagnostic and get a corrected program that actually passes tulpa check.

Explain

Walks through unfamiliar code and language features, from units of measure to safety envelopes.

Agent mode

Plans a change, runs tulpa check, run, test and prove in a sandbox, repairs from the diagnostics and shows you a diff to approve.

Knows the ecosystem

Ships with a knowledge pack of the Tulpa docs, examples and std/, and knows .RAV IDE, Tulpa Field and TulpaTutor.

Built for phones

Native Android and SwiftUI iOS apps with streaming chat, projects, an editor and tools.

The model

Trained on code the compiler has already checked.

Tulpa AI is specialized on {{ai.examples}} chat and agent examples, and every one was verified against the real compiler: writing, fixing genuine errors, explaining, documenting and multi-step tool use. Each new model sits the same exam as the one it replaces, and goes live only if it scores higher.
