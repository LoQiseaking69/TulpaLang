What makes Tulpa different

Established ideas, finally in one language.

Units, contracts, statecharts and reactive programming each have a long history. Tulpa makes them cooperate as native parts of one language, aimed at physical systems.

Lineage

Where the ideas come from.

Dimensional programming

From scientific computing, F# and Modelica. Units are embedded in expressions and enforced at runtime.

Design by contract

From Eiffel, SPARK and Dafny. Executable specifications with contract fuzzing.

State-based systems

From UML Statecharts and SCXML. Native syntax and runtime.

Reactive programming

From ReactiveX and Lustre. Signals, derived values and event-triggered rules.

Industrial control

From IEC 61131-3 and PLC environments. Device abstractions, PID and timing constraints.

Systems compilation

From Rust and LLVM toolchains. Bytecode execution and native code generation.

Best use cases

Where Tulpa fits.

  • Robotics and mechatronicsMachines for behaviour, reactive rules for sensors, envelopes for limits.
  • Hardware regression testingRecord on the rig once, then replay in CI.
  • Safety-oriented control logicContracts, invariants and monitors catch invalid states early.
  • Sensor and actuator bring-upI2C::scan(), registers from the REPL, and --trace.
  • Embedded and control educationReadable syntax, simulated hardware, built-in PID and kinematics.
  • Engineering experimentationLearning, simulation, RTL and boards in one language.
Install

Rust 1.82+ required. This gets you the 3.2 libraries today.

Shell
git clone {{tulpa.repo}}.git
cd TulpaLang && cargo build --release
./target/release/tulpa examples/tour/main.rav

x86_64, arm64 (Raspberry Pi 3/4/5) and armv7 tarballs, or a .deb, from Releases.

Shell
sudo apt install ./tulpa_<version>_<arch>.deb
# or
tar xzf tulpa-<version>-<target>.tar.gz && sudo ./install.sh /usr/local

Intel and Apple-silicon tarballs are attached to each release.

Shell
tar xzf tulpa-<version>-aarch64-apple-darwin.tar.gz
sudo mv tulpa /usr/local/bin/

The HermiSim installer bundles tulpa.exe and std/, and can add Tulpa to your PATH. You can also build from source with Rust.
