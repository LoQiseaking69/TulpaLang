# Projects, files & sharing

Projects live in the app's private storage, one folder each. From **Projects**:

- **New project** from a template: Blank, Phone sensor loop, State machine, or Contract + check().
- **Open as project** from any library example gives you an editable copy.
- Long-press a project to rename, duplicate, share or delete it.

## Importing

Open a `.rav` file from a file manager or a chat app with **Open with Tulpa Field**, or share text
to the app; it lands in the **Inbox** project.

## Sharing

**Share** on a file sends it as text or as a `.rav` file. Files your programs write — a `track.csv`,
a `counter.vcd` waveform — appear in the project's file list and in the Run screen's *Artifacts*
row, where you can share them to a desktop running HermiSim or GTKWave.

## Libraries

`import "std/rtl"`, `"std/eda"`, `"std/lipm"`, `"std/rl"`, `"std/topics"` and `"std/frame"` work
exactly as on the desktop — the same library files ship inside the app.
